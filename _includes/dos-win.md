<p align="justify">Βρισκόμαστε στις αρχές του 1990 και η άλλοτε κραταιά συνεργασία μεταξύ της Microsoft και της IBM κλυδωνίζεται από τους μεγάλους τριγμούς. Οι δύο εταιρείες αναπτύσσουν το OS/2, το λειτουργικό σύστημα που θα αντικαταστήσει το τρέχον λειτουργικό σύστημα MS-DOS, που βρίσκεται στην έκδοση 5.0. Το εταιρικό διαζύγιο θα βρει την Microsoft να έχει ήδη κυκλοφορήσει τα Windows 3.0, ενώ η έκδοση 1.3 του λειτουργικού OS/2 θα κυκλοφορήσει μερικούς μήνες μετά. Η Microsoft, μετά από το διαζύγιο με την IBM και νιώθωντας τον έντονο ανταγωνισμό (Apple, MacOS), ρίχνει το βάρος στην βελτίωση του λειτουργικού της συστήματος Windows 3.0.</p>  

<p align="justify">Μερικά χρόνια πριν, το 1987, η Microsoft κυκλοφορεί το MS-DOS 4.0, όπου περιλαμβάνεται για πρώτη φορά το DOS Shell, μια γραφική διεπαφή για την διαχείριση αρχείων. Η διεπαφή εστιάζει στην φιλικότητα με τον χρήστη (user friendly), που βελτιώνεται κατακόρυφα σε σχέση με την γραμμή εντολών (command line). Παρέχει έναν File Manager, για την διαχείριση του συστήματος δίσκων του υπολογιστή (σκληροί δίσκοι και οδηγοί δισκέτας), μέσα από ένα υποτυπώδες γραφικό παραθυρικό περιβάλλον. Μέσα στο παράθυρο του γραφικού κελύφους, τα αρχεία εμφανίζονται με την μορφή λίστας, ενώ παρέχονται πληροφορίες σχετικά με την ημερομηνία δημιουργίας τους και το μέγεθός τους. Στην έκδοση 5.0 του MS-DOS που κυκλοφορεί τον Απρίλιο του 1991, περιλάμβανεται μια βελτιωμένη έκδοση του DOS Shell, η οποίο “μοιάζει” με την εφαρμογή Norton Commander της Symantec που βρίσκεται ήδη στην αγορά. Πρόκειται για διεπαφή διαχείρισης των αρχείων συστήματος μέσα από σύστημα δύο κεντρικών παραθύρων, που βρίσκονται δίπλα-δίπλα. Σε κάθε παράθυρο προβάλονται πληροφορίες σχετικά με τον κατάλογο των αρχείων ή σχετικά το επιλεγμένο αρχείο. Η διαχείριση γίνεται με εντολές που βρίσκονται ομοδοποιημένες σε drop-down μενού. Μερικούς μήνες αργότερα, τον Μάρτιο του 1992, μια νέα, βελτιωμένη, γραφική έκδοση του File Manager πρόκειται να ενσωματωθεί στην νέα έκδοση του λειτουργικού συστήματος με την ονομασία MS Windows 3.1, που θα κυκλοφορήσει η Microsoft.</p>

<p align="justify">Τα MS Windows 3.1 αποτέλεσαν μια μεγάλη εμπορική επιτυχία για την Microsoft. Η μετάβαση από τις μαύρες οθονες του MS-DOS σε γραφικό περιβάλλον θεωρήθηκε κοσμογονική. Παρόλα αυτά το νέο λειτουργικό τρέχει επάνω σε DOS και θεωρείται ως ένα κέλυφος (shell). Το DOS Shell εξακολουθεί να υπάρχει με την μορφή του Program Manager και στα Windows 3.1 με νέα, βελτιωμένη γραφική διεπαφή. Δεν είναι τυχαίο όπου στο Help των Windows 3.1, το νέο λειτουργικό αναφέρεται ως “Program Manager ver 3.1”! Η διεπαφή (GUI) του νέου λειτουργικού χρησιμοποιεί πλέον παράθυρα, εικονίδια, μενού εντολών και ποντίκι (WIMP paradigm). Το ποντίκι μετατρέπεται σε βασικό εργαλείο χειρισμού, ενώ χρησιμοποιείται σχεδόν αποκλειστικά το αριστερό πλήκτρο του. Η εξοικείωση του χρήστη με το ποντίκι στο νέο γραφικό περιβάλλον των Windows 3.1, θεωρείται τόσο απαραίτητη, ώστε η Microsoft προσθέτει tutorial για την εκμάθησή του. Στο νέο, λειτουργικό σύστημα, χρησιμοποιούνται εικονίδια εφαρμογών αντί για λίστες αρχείων. Επιπλέον, τα παράθυρα των εφαρμογών (application windows) μπορούν να αλλάζουν διαστάσεις (resize), να επικαλύπτονται (overlap) και να ελαχιστοποιούνται (minimize)-μεγιστοποιούνται (maximize), επιτρέποντας την πολυδιεργασία (multitasking) μεταξύ των εφαρμογών. Μέσα από το γραφικό περιβάλλον των Windows 3.1, ο χρήστης έχει την δυνατότητα να δει υψηλής (για την εποχή) ποιότητας γραφικά, να αναπαράγει και να ηχογραφήσει μουσική, να χρησιμοποιήσει δίσκους CD και όλα αυτά σε μια multimedia εποχή που ξεκίναγε να ανατέλλει (1992).</p>
